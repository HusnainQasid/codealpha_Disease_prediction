# 🏥 Disease Prediction System

## 📌 Objective
Predict diseases based on patient symptoms and medical data using machine learning.

## ⚙️ Approach
Applied multiple classification algorithms:
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

## 📊 Dataset
- Training and Testing datasets in Excel format
- Target column: `prognosis`

## 🚀 How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python main.py

## 📈 Output
- Accuracy of each model
- Classification report
- Best model selection
